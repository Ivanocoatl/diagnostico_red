Módulo 0: Intro a la CLI vs GUI

La GUI oculta la complejidad mediante abstracciones visuales, limitando la automatización. La CLI se fundamenta en flujos de texto que se comunican directamente con el shell.

Funcionamiento Interno

El intérprete lee de stdin, busca el binario en la variable PATH, genera un proceso hijo mediante fork()/exec() y devuelve la salida a stdout.

Comparativa de Ecosistemas

  • CMD: Texto plano, ejecución secuencial batch.
  • PowerShell: Objetos .NET (CLR), Verbo-Sustantivo.
  • Bash: Filosofía Unix, tuberías de texto, portable.
Error Común: "Command not found"
El binario no está en el PATH. Solución: echo %PATH% o echo $PATH

Acceso Remoto: Telnet vs SSH

Telnet transmite texto plano (packet sniffing). SSH provee túnel cifrado asimétrico TCP 22.

Módulo 3: Windows Network

Consola Tradicional (NDIS)

  • ipconfig /all MAC, DHCP, DNS.
  • ipconfig /release Mensaje DHCPRELEASE.
  • ipconfig /renew Mensaje DHCPDISCOVER.
  • ipconfig /flushdns Limpia caché de resolución.

Cmdlets Modernos (PowerShell)

  • Get-NetAdapter Adaptadores e ifIndex.
  • New-NetIPAddress Requiere UAC elevado. Si no: "Acceso Denegado".

Diagnóstico y Troubleshooting

ÁRBOL DE FALLAS

¿IP de destino asignada?
├── [169.254.x.x] ──> APIPA (Falla DHCP)
│ Solución: dhclient o /renew
└── [IP Válida] ──> ¿Ping a Gateway?
├── [No] ──> ARP Duplicado (arp -a)
└── [Sí] ──> Falla DNS (/etc/resolv.conf)

ping Verifica capa 3.

traceroute Mide saltos por TTL.

netstat Puertos TCP (LISTEN, ESTABLISHED).
