Bienvenido al Laboratorio CLI

De Cero a Administrador de Sistemas (Windows vs. Linux)

Has entrado a un simulador interactivo diseñado para enseñarte desde lo más básico hasta lo más avanzado en administración de redes y sistemas operativos[cite: 1]. Aquí no solo leerás teoría; interactuarás con consolas simuladas, escucharás el *feedback* de tus acciones y comprenderás la anatomía de cada comando.

❓ ¿Qué es la Consola y por qué la necesitamos?

En la informática moderna, la mayoría interactúa mediante una Interfaz Gráfica de Usuario (GUI). Sin embargo, los administradores de sistemas trabajan casi exclusivamente con la Interfaz de Línea de Comandos (CLI)[cite: 1]. La terminal no es una reliquia del pasado; es el medio más preciso, potente y eficiente para comunicarse con una computadora[cite: 1]. Otorga control absoluto, permitiendo automatizar procesos y administrar servidores remotamente sin transferir costosos datos gráficos[cite: 1].

Los Dos Ecosistemas que Dominarás

🪟

Ecosistema Windows

  • CMD (Símbolo del Sistema): Heredada de MS-DOS. Sencilla y usada para diagnósticos rápidos[cite: 1].

Módulo 1: El Primer Contacto con la Terminal

Nivel: Absoluto Cero. Aprenderás a moverte, manipular archivos y elevar privilegios[cite: 1].

1.1 Limpieza de Pantalla

Cuando ejecutas muchos comandos, la terminal se satura. Limpiar la pantalla te permite volver a enfocarte[cite: 1]. Al usar el comando CLS se limpiará el búfer de visualización[cite: 2].

Windows CMD
C:\Users\Admin> cls
  • Acrónimo: CLS significa Clear Screen (Limpiar Pantalla)[cite: 1].
  • El porqué: Comando interno de tres letras sin parámetros[cite: 1].
  • Resultado: Pantalla totalmente limpia[cite: 1].
  • Error común: `'cls' is not recognized...`[cite: 1].
    Solución: Estás en un entorno Linux o tu PATH está dañado[cite: 1].
Linux Bash
root@kali:~# clear
  • Acrónimo: Clear significa Limpiar[cite: 1]. Lo mismo se logra presionando Ctrl-l[cite: 3].
  • El porqué: Es un binario ejecutable localizado en /usr/bin/clear[cite: 1].
  • Resultado: Desplaza el buffer hacia abajo simulando pantalla limpia[cite: 1].
  • Error común: `bash: clear: command not found`[cite: 1].
    Solución: Instalar paquete ncurses-bin[cite: 1].

1.2 Consulta y Exploración de Directorios

Ver qué archivos y carpetas están en tu ubicación actual es vital para saber dónde estás[cite: 1]. En Linux, el símbolo `~` indica que estás en tu directorio home[cite: 3].

Windows
C:\> dir /w
  • Acrónimo: DIR significa Directory (Directorio)[cite: 1].
  • Elementos: /p (Page) pausa por página, /w (Wide) formato ancho de visualización[cite: 1, 2].
  • Falla: File Not Found si la ruta no existe[cite: 1].
Linux
~# ls -l -a
  • Acrónimo: LS significa List (Listar)[cite: 1].
  • Elementos: -l (Long) listado detallado, -a (All) muestra archivos ocultos que empiezan con punto (.)[cite: 1, 3].
  • Solución a fallas: Respetar mayúsculas/minúsculas, Linux es case-sensitive[cite: 1].

1.4 Copiado y Movido de Archivos

Transferir o renombrar información. En Linux, la filosofía dicta que "el silencio es éxito"; si un comando funciona, no arroja mensajes de confirmación[cite: 1].

Copiado (Windows) copy [origen] [destino][cite: 1]

Si hay espacios en la ruta, usar comillas dobles. Error común: The system cannot find the file specified[cite: 1]. El comando move se utiliza para renombrar y mover[cite: 2].

Copiado (Linux) cp -r [origen] [destino][cite: 1, 3]

CP (Copy). -r (recursivo) para copiar carpetas llenas[cite: 1, 3]. Para mover o renombrar se usa mv[cite: 1, 3, 4].

1.5 Elevación de Privilegios (Super Usuario)

Para modificar red o software, requieres permisos especiales[cite: 1]. En Windows, abrir CMD como Administrador o usar runas /user:Administrador cmd.exe[cite: 1].

El Entorno Linux (root vs sudo)

Linux cuenta con el usuario root. Usar siempre root es peligroso, reduce la seguridad[cite: 3].

  • sudo [comando]: SUDO (SuperUser Do). Ejecuta un solo comando como administrador. Pide tu contraseña[cite: 1, 3]. No cambia el entorno ni requiere comillas especiales[cite: 3].
  • su -: SU (Switch User). Inicia sesión persistente como root, cargando su perfil[cite: 1, 3]. Usualmente pide la contraseña de root[cite: 1]. Usar el guion (-) es importante para simular login[cite: 3].
Error: "user is not in the sudoers file" -> Falla: No perteneces al grupo administrativo. Solución: Modificar /etc/sudoers[cite: 1, 3].

1.6 Conexiones Remotas: Seguras vs Inseguras

Inseguro: TELNET

Teletype Network. Envía contraseñas en texto plano. Interceptable con Wireshark[cite: 1]. Su uso requiere instalar funcionalidades extra en Windows Vista o superior[cite: 2].

Seguro: SSH

Secure Shell. Tráfico encriptado criptográficamente[cite: 1]. Previene ataques Man-in-the-Middle. Estándar de la industria[cite: 1]. Opera por defecto en el puerto 22[cite: 1, 6].
